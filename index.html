Tentang

Saya Dea Ayu Riska Amalia, mahasiswa semester 3 Program Studi Bisnis Digital di UIN K.H. Abdurrahman Wahid Pekalongan. Saya tertarik pada pengembangan website, pemasaran digital, dan cara teknologi membantu usaha kecil tumbuh lebih cepat.Saya memiliki semangat untuk terus belajar, mengembangkan kemampuan, dan menambah pengalaman baru. Melalui proses pembelajaran ini, saya ingin memahami cara membuat website yang menarik, fungsional, dan bermanfaat. Saya percaya bahwa dengan kemauan untuk belajar dan terus berlatih, saya dapat mengembangkan potensi diri serta mempersiapkan diri untuk menghadapi dunia kerja di era digital.

Saat ini saya sedang mempelajari HTML, CSS, dan JavaScript untuk membangun tampilan web yang rapi, responsif, dan mudah digunakan. Website ini adalah hasil belajar saya pada mata kuliah Web Programming.
